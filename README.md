AP-HUNTER 🔐 — ESP32-Based Office Wi-Fi Monitoring Dashboard

AP-HUNTER is an ESP32-powered web dashboard designed to assist in monitoring office Wi-Fi security.
The system uses an authorized laptop to collect active device information from the network’s ARP table and forwards it to an ESP32-hosted web interface for visualization.

🔑 Key Features

ESP32-based Web Dashboard (AP Mode)

Office Wi-Fi device discovery using ARP method

Laptop-to-ESP32 middleware communication (Python)

Live device count & auto-refresh UI

Ethical, non-intrusive monitoring approach

⚠️ Note

This project does not perform Wi-Fi attacks or packet sniffing.
All data is collected through authorized and ethical methods.
